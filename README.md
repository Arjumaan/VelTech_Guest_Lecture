# 🎓 MERN & AI Masterclass — VelTech Guest Lecture

![MERN & AI Banner](https://img.shields.io/badge/MERN-Masterclass-cyan?style=for-the-badge&logo=react)
![Theme](https://img.shields.io/badge/UI-Neomorphism-pink?style=for-the-badge)

A premium, interactive showcase website designed specifically for the **3-Day MERN Stack & AI Integration Guest Lecture** at VelTech Engineering University. 

This repository houses the frontend codebase for the lecture's companion website, serving as an interactive curriculum guide, concept cheat sheet, and project assignment portal for the participating students.

---

## 🚀 Features

- **📖 Interactive Curriculum**: Comprehensive breakdown of Day 1 (React/Frontend), Day 2 (Node/Express Backend), and Day 3 (AI Integration).
- **🎨 Premium UI/UX**: Built entirely from scratch using a custom "Soft-UI" (Light Neomorphism) design system with vibrant neon accents to keep students engaged.
- **🎲 Dynamic Project Picker**: Includes an interactive, animated dice-rolling system that randomly assigns 1 of 30 unique, AI-integrated MERN project ideas to students.
- **📁 Direct Asset Downloads**: Integrated download links for the official daily PowerPoint presentations.
- **💡 Beginner Friendly**: Features custom flow diagrams, "Restaurant" analogies for client-server architecture, and exact terminal commands to bridge the gap for absolute beginners.

---

## 🛠️ Technology Stack

- **Framework**: React (Bootstrapped with Vite)
- **Routing**: React Router DOM (\`HashRouter\` optimized for GitHub Pages)
- **Animations**: Framer Motion
- **Icons**: Lucide React
- **Styling**: Vanilla CSS (Custom Neomorphic Design System)

---

## 📚 Curriculum Overview

### Day 1: The Frontend (React.js)
- Setting up a React environment (Node, NPM, Vite)
- HTML5 Semantics & CSS3 Layouts (Flexbox/Grid)
- Core JavaScript (ES6+, DOM, Promises)
- React Fundamentals (JSX, Components, Props, State, \`useEffect\`)

### Day 2: The Backend (Node, Express, MongoDB)
- Node.js & NPM Deep Dive
- REST API Design with Express
- Database Architecture with MongoDB & Mongoose
- Security: JWT Authentication & Password Hashing

### Day 3: AI & Full-Stack Integration
- The MERN Flow (Connecting React to Express)
- Prompt Engineering basics
- Integrating Google Gemini / OpenAI APIs into the backend
- Handling streaming responses in React

## 💻 Local Development

To run this website locally on your machine:

1. **Clone the repository**
   \`\`\`bash
   git clone https://github.com/Arjumaan/VelTech_Guest_Lecture.git
   cd VelTech_Guest_Lecture
   \`\`\`

2. **Install dependencies**
   \`\`\`bash
   npm install
   \`\`\`

3. **Start the development server**
   \`\`\`bash
   npm run dev
   \`\`\`

4. Open your browser and navigate to \`http://localhost:5173\`

---

## 🌐 Deployment

This project is configured to be deployed on **GitHub Pages**. 
The \`vite.config.js\` is pre-configured with the correct \`base\` path for deployment.

Build the production bundle:
\`\`\`bash
npm run build
\`\`\`
